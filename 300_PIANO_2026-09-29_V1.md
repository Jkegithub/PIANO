# 300_PIANO — Planung V1 (29.09.2026)

*Erster Entwurfsstand. Ein neuer Stand bekommt eine neue Datei; die höchste Nummer gilt.*

## Ziel

Ein Klavier im Browser: lernen als Anfänger, spielen als Profi. **Maßstab ist die natürliche
Klangfarbe.** Eine erfahrene Pianistin soll Freude daran haben. Später soll eine Online-Variante
über GitHub laufen.

## Entscheidung 1: Klangquelle *(Recherche 29.09.2026)*

Für einen natürlichen Klang braucht es gesampelte Flügelaufnahmen mit vielen Anschlagstufen.
Synthese reicht dafür nicht [PLAUSIBEL].

**Empfehlung: Salamander.** Es ist die einzige Quelle mit 16 Anschlagstufen, die frei
weitergegeben werden darf. Die Namensnennung kommt in `README.md` und in die App.
Für das Web wird ein komprimierter Satz gebraucht (Original ≥ 394 MB FLAC). Daraus folgt
**Ladestrategie** als eigene Aufgabe: erst eine mittlere Anschlagstufe laden, die übrigen nachladen.

## Entscheidung 2: Eingabe

| Eingabe | Anschlagdynamik | Eignung |
|---|---|---|
| Computertastatur | **keine**: jede Taste ist gleich laut | Anfänger, Ausprobieren |
| Maus/Touch auf der Bildschirmtastatur | kaum | Anfänger |
| **MIDI-Keyboard/Digitalpiano über Web MIDI** | **voll** | **Profi**. Ohne Dynamik hat eine Pianistin keine Freude daran |

Web MIDI laut caniuse (29.09.2026): Chrome ab 43, Edge ab 79, Firefox ab 108, Chrome Android.
**Safari und iOS nicht.** Brave basiert auf Chromium, sollte also funktionieren [PLAUSIBEL, zu testen].

## Funktionen

**Gemeinsam:** 88 Tasten, Sustain-Pedal (Taste oder MIDI-CC64), Lautstärke, niedrige Latenz.

**Anfänger:**
- Tastenbeschriftung (C–D–E …, wahlweise Do–Re–Mi) und Zuordnung zur Computertastatur
- Fallende Noten bzw. Leuchttasten: Das Stück zeigt, was als Nächstes kommt, und wartet auf den richtigen Ton
- Tempo drosseln, Hände getrennt üben
- Übungsstücke: nur gemeinfreie Werke oder eigenes Material

**Profi:**
- Volle Anschlagdynamik über MIDI, Velocity-Kurve einstellbar
- Pedal mit Halbpedal, falls die Samples es hergeben [UNSICHER]
- Aufnahme und Wiedergabe des eigenen Spiels, Export als MIDI
- Stimmung (A = 440/442/443 Hz), Metronom
- Oberfläche ohne Lernhilfen, nur Klang

## Technik (Vorschlag)

- Statische Seite (HTML/JS), dadurch als GitHub Pages hostbar, ohne Server
- Web Audio API; Sampler z. B. über Tone.js oder eigene Implementierung. **Noch zu entscheiden,
  vorher prüfen, ob Tone.js Anschlagstufen sauber abbildet**
- Samples als MP3/OGG, gestaffelt geladen
